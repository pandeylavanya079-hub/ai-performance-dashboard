# 🧠 Elite AI Productivity & Performance Command Center

An interactive, high-performance daily database dashboard, bio-analytics tracker, monthly trend analysis, and automated weak-area diagnostic system.

## 🚀 Features

- 📊 **Executive Scorecard**: Real-time tracking of Productivity (0-100), Health, Learning, Fitness, Discipline, Consistency, and Goal Hit %.
- ⚠️ **AI Weakness Diagnostic Reminders**: Automatically detects score slippages or habit drifts and suggests 1-click corrective action routines.
- 📆 **Month-wise Progress View**: 30-day continuous score trajectory curves, 30-day habit heatmaps, and Month-over-Month growth matrix.
- 📅 **Custom Schedule & Priorities**: Add, check off, and delete custom daily activities and MIT priorities with LocalStorage persistence.
- 🥗 **Macronutrient & Circadian Focus Analytics**: Visualizes nutrition splits and focus density curves.

## 💻 Local Setup & Usage

```bash
# Clone the repository
git clone git@github.com:lavanya-pixel/ai-performance-dashboard.git

# Serve locally
python -m http.server 8080
```
Open `http://localhost:8080` in your web browser.
